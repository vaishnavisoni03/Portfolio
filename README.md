# Portfolio

A clean, modern, and responsive personal portfolio website for **Vaishnavi Soni**, a first-semester B.Tech CSE (AI & ML) student at JECRC University, Jaipur (Batch 2026 – 2030).

## Tech Stack
- **HTML5** (Semantic structure)
- **Vanilla CSS3** (Custom properties, responsive flexbox & grid, micro-animations)
- **Vanilla JavaScript** (Mobile menu, active scroll tracking, project filters, contact form handler)

## Sections & Features
- **Hero Section:** Student identity, graduation batch (2026–2030), location badge, and quick stats bar.
- **About Me:** Academic background, personal curiosity, and quick facts cards.
- **Skills & Competencies:** Categorized areas covering Programming Fundamentals, Web Basics, AI Foundations, and Tools.
- **Education:** B.Tech in CSE (AI & ML), JECRC University, Jaipur (2026–2030) with first-year coursework highlights.
- **4-Year Learning Roadmap:** Milestone overview from Year 1 (2026–2027) through graduation (2029–2030).
- **Work & Projects:** Interactive category filters (`All`, `Web Basics`, `Python & Logic`, `AI & ML`) featuring the live portfolio and learning problem solutions.
- **Get in Touch:** Direct contact channels (Email, LinkedIn, GitHub) alongside an interactive message form.

## Project Structure
- `index.html` - Semantic markup and content
- `style.css` - Design system, modern typography, off-white/navy aesthetic
- `script.js` - Lightweight vanilla JS interactions
