# Portfolio

A clean, modern, and responsive personal portfolio website for **Vaishnavi Soni**, a first-semester B.Tech CSE (AI & ML) student at JECRC University, Jaipur.

## Tech Stack
- **HTML5**
- **Vanilla CSS3**
- **Vanilla JavaScript**

## Features
- Minimalist design with an off-white background, navy typography, and muted-blue accents.
- Responsive layout for desktop and mobile devices.
- Smooth scroll navigation and interactive mobile hamburger menu.
- Subtle scroll-reveal animations using `IntersectionObserver`.

## Structure
- `index.html` - Semantic markup and structure
- `style.css` - Custom styling, layout, and animations
- `script.js` - UI interactions, mobile navigation, and scroll effects
