# Vaishnavi Soni - Personal Portfolio & AI Roadmap

A modern, editorial, and interactive personal portfolio, 4-year academic roadmap, and curriculum vitae for **Vaishnavi Soni**, a first-semester B.Tech CSE (AI & ML) student at JECRC University, Jaipur (Batch 2026–2030).

Built with a luxurious **Dark Burgundy & Rose Gold** aesthetic, featuring frosted glassmorphism, responsive micro-interactions, an ambient canvas particle system, and modular components.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup, accessible ARIA roles, responsive meta tags.
- **Vanilla CSS3:** Custom properties (CSS variables), glassmorphic backdrops, flexbox, CSS Grid, `@media print` rules.
- **Vanilla JavaScript:** 100% dependency-free Canvas API, IntersectionObserver, and modular event listeners.
